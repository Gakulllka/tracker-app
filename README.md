# Delta-tasker

Операционный монитор: месячный бюджет часов между аналитиком и руководителем.
План и факт по каждой задаче, лимит месяца на домен, автоматическое отсечение
при перерасходе, двусторонние сигналы. Итог месяца — версионируемая презентация.

Часть экосистемы Delta. База знаний и общие правила — в `C:\Delta\DataBase`
и `C:\Delta\AGENTS.md`.

---

## Что нужно для запуска

| Требование | Зачем |
|------------|-------|
| Node.js 20 или новее | среда выполнения |
| PostgreSQL | база данных (сейчас — Supabase) |

Проверить версию Node: `node -v`

---

## Запуск на новой машине

```bash
# 1. Установить зависимости (создаст node_modules, ~1 ГБ)
npm install

# 2. Настроить подключение к базе
#    Скопировать .env.example в .env и вписать реальные значения
cp .env.example .env

# 3. Создать таблицы в базе (только если база пустая)
npm run db:push

# 4. Запустить
npm run dev
```

Откроется на **http://localhost:3003**

Папку `node_modules` при переносе копировать не нужно — она создаётся
командой `npm install` за пару минут.

## Порт

Задан **в одном месте** — переменная `PORT` в `.env`. Меняется только там.

Next.js не читает порт из `.env` самостоятельно, поэтому запуск идёт через
`scripts/run.mjs`: он подхватывает переменную и передаёт её дальше. Работает
одинаково на Windows, macOS и Linux.

Занятые порты экосистемы: 3000 — Delta-hub, 3002 — Delta-finance,
5173 — Delta-BA. Delta-tasker занимает **3003**.

## Структура

```
src/
├── app/
│   ├── page.tsx          Главный экран трекера
│   ├── auth-gate.tsx     Вход, проверка сессии, выбор домена
│   ├── admin/            Админ-панель
│   └── api/              30 серверных маршрутов
├── components/
│   ├── views/            Вкладки: таблица, беклог, вопросы, слайды, протоколы, чат
│   ├── dialogs/          Модальные окна
│   └── ui/               shadcn/ui — вручную не редактируется
├── hooks/                Реакции на изменения: права, синхронизация, клавиши
└── lib/                  Логика без интерфейса: стор, метрики, импорт, права
prisma/schema.prisma      Модель данных — единственный источник правды
scripts/run.mjs           Запускатель с портом из .env
```

Правило: если функцию можно вызвать без React — ей место в `src/lib/`.

## Чего здесь нет и почему

`node_modules`, `.next` — создаются автоматически, в репозиторий не попадают.

`.env` — содержит пароль от базы, в git не хранится. Шаблон лежит
в `.env.example`.
